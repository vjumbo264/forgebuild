# Effects not established as original Keyflaw effects

Previous notes calling all handwritten ms_* shaders 'Keyflaw-matched' are withdrawn. Recovered implementations and provenance hashes live in keyflaw-reference/manifest.json.

The parametric Colour Match is custom (specified by the operator), not a native Keyflaw effect. The existing ms_white_balance, ms_selective_color, ms_channel_mixer, ms_highlights_shadows, ms_duotone, ms_gradient_map, ms_split_toning, ms_clarity and ms_bloom_halation have NOT been established as absent from Keyflaw merely because their exact names differ. Do not list them as justified custom substitutes without a complete matching catalog check. They remain legacy/unverified and must not be represented as copied original effects.

Sealed original Glow/Curves/Levels/HSL are not 'not in Keyflaw'; their code is inaccessible in the inspected shader strings and needs reference calibration as recorded separately. Original Sharpen/Unsharp/Tritone/Diffusion/Haze/Vignette/Film Grain have readable code and must use it.
