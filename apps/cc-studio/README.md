# MOTIONSALT CC Studio (v2)

Standalone, 100% offline mobile Android color grading studio and Keyflaw 1.4.9 effect suite builder for Victor Jumbo (MOTIONSALT, Nigeria).

## Core Capabilities
- **Offline Look Fitting**: Extracts 3D color grade from base and target frame pairs using a staged mathematical pipeline (1D Tone curves, 3x3 chromatic matrix regression, 33x33x33 residual lattice with Laplacian smoothing).
- **Zero-Distortion Hald Level 8**: True identity 512x512 PNG generated by passing pixels through the single source of truth color transform.
- **3D .cube LUT Export**: Standard 33x33x33 Adobe/Resolve LUT export.
- **Native Keyflaw 1.4.9 .kfpack**: Directly creates importable effect packs (fused single look or full effect suites) saved to `Downloads/MOTIONSALT/CC Studio/`.
- **17 In-Scope Effects**: Strict GLSL ES 1.00 shaders compliant with Keyflaw 1.4.9 specifications (expandBounds bloom, COLOR params, multi-pass blur).
- **Real-Time Tune & Inspection**: 8 view modes (Result, Wipe, Side-by-side, Top/bottom, Vs Target, Difference with gain, Channels, Scopes) and 4 live scopes (RGB Parade, Vectorscope, Histogram, Waveform).

## 100% Offline Contract
The app declares NO `android.permission.INTERNET` or `ACCESS_NETWORK_STATE`. It includes no analytics, no remote fonts, no cloud dependencies, and zero telemetry. All operations execute strictly on-device.
